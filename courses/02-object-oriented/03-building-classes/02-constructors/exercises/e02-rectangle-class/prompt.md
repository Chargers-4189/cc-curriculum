`main` is already written. Finish the `Rectangle` class:

- A **no-arg constructor** that makes a 1 by 1 rectangle
- A constructor that takes a width and a height (both `double`)
- `getArea()`: gives back width times height
- `getPerimeter()`: gives back all four sides added up

```
1.0 x 1.0: area 1.0, perimeter 4.0
4.0 x 40.0: area 160.0, perimeter 88.0
3.5 x 2.0: area 7.0, perimeter 11.0
```

*Adapted from Programming Exercise 9.1 in Introduction to Java Programming (Liang).*
