Follow along with the lesson in `Duck.java` and `Nature.java`. Each section of the lesson has matching `// --- Section ---` comments.

1. Make a `Duck` with `new` before writing any constructor. Who wrote the constructor?
2. Write a no-arg constructor that prints `Quack` and gives the duck a default size and name.
3. Add a constructor that takes a size, and one that takes a size and a name. Make a duck with each.
4. Print the name of a duck whose name was never set.
5. Write `setSize(int size)` using `this`.

## In Labs

```bash
ccm get duck-demo
cd duck-demo
```

Run `Nature` with the Run button, or:

```bash
javac *.java
java Nature
```
