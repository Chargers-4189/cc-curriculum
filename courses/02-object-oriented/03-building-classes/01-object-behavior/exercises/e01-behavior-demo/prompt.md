Follow along with the lesson in `Dog.java`, `Fish.java` and `BehaviorTester.java`. Each section of the lesson has matching `// --- Section ---` comments: the class code goes in `Dog.java` or `Fish.java`, and the code that uses it goes in `BehaviorTester.java`.

1. Give `Dog` a `size` and a `name`, and write a `bark()` that depends on the size. Make three dogs of different sizes bark.
2. Give `Fish` a `diet` and write `eat(int numOfBites)`.
3. Write `getWeight()` and store what it gives back.
4. Write `swim(int distance, int speed)` and call it.
5. Write getters and setters for the dog's name and size.

## In Labs

```bash
ccm get behavior-demo
cd behavior-demo
```

Run `BehaviorTester` with the Run button, or:

```bash
javac *.java
java BehaviorTester
```
