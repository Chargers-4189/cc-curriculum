A `Car` knows how much `fuel` it has (in gallons) and its `mpg` (miles per gallon). `main` is already written. Add three methods to `Car`:

- `drive(double miles)` uses up `miles / mpg` gallons of fuel
- `getFuel()` gives back (returns) how much fuel is left
- `milesLeft()` gives back how many miles the car can still go: `fuel * mpg`

```
Fuel left: 8.0
Fuel left: 4.0
Miles left: 100.0
```
