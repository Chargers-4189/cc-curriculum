Swap the robots: after your code, `first` should refer to Volt and `second` should refer to Bolt.

Don't make any new robots and don't change their names. Only move the references around.

```
First: Bolt, second: Volt
First: Volt, second: Bolt
```

**Hint:** if you do `first = second;` right away, nothing refers to Bolt anymore. Draw it! You'll need a third variable to hold on to Bolt.
