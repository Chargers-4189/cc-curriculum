This program is supposed to make **two** robots, Bolt and Volt. Run it. It prints:

```
Volt has 40% battery
Volt has 40% battery
```

Draw the memory map to find out why, then fix **one line** so it prints:

```
Bolt has 100% battery
Volt has 40% battery
```

## In Labs

Prefer to work in Charging Courses Labs? Download it, write your code in `Main.java`, and check it:

```bash
ccm get fix-the-alias
cd fix-the-alias
ccm test
```
