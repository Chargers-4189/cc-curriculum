Follow along with the lesson in `References.java`. `Person.java` is already done; you'll only use it. Each section of the lesson has a matching `// --- Section ---` comment.

1. Make an `int` and a `Person`, and draw the memory map for both.
2. Copy an `int` into another variable, change the copy, and print the original.
3. Copy a `Person` variable into another variable and print the name through the new one.
4. Change the name through one variable and print it through the other. Predict first!
5. Make a `null` person and print it. Then try calling `getName()` on it, read the error, and comment it out.

## In Labs

```bash
ccm get references-demo
cd references-demo
```

Run `References` with the Run button, or:

```bash
javac *.java
java References
```
