Follow along with the lesson in `Cat.java` and `CatTester.java`. Each section of the lesson has a matching `// --- Section ---` comment in one of the files.

1. In `Cat.java`, give a cat its instance variables: `name`, `color`, `breed` and `size`.
2. Add the methods `meow()`, `walk(double pace)` and `sleep()`.
3. In `CatTester.java`, make a `Cat` with `new` and tell it to `meow()`.
4. Use the dot operator to set its name, then make it `walk`.
5. Make a second cat with a different name. Make both of them do something.

## In Labs

```bash
ccm get cat-demo
cd cat-demo
```

Run `CatTester` (it has the `main` method) with the Run button, or:

```bash
javac *.java
java CatTester
```
