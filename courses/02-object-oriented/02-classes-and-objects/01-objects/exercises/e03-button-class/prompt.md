`main` is already written. It makes two buttons and uses them, but the `Button` class is empty. Write it:

- A `Button` **knows** its `label` and its `color` (both `String`s)
- A `Button` **does** two things:
  - `push()` prints the label, then ` was pushed`
  - `release()` prints the label, then ` was released`

```
Backspace was pushed
Backspace was released
Nuclear launch was pushed
The launch button is Red
```
