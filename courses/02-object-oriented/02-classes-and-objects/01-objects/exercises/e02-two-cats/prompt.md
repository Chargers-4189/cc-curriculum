The `Cat` class is already written at the bottom of the file. In `main`, use it:

1. Make a `Cat` named Luna and make her walk at pace 1.5.
2. Make a second `Cat` named Biscuit and make him meow.
3. Make Luna meow.

```
Luna is walking at pace 1.5
Biscuit says meow
Luna says meow
```

## In Labs

Prefer to work in Charging Courses Labs? Download it, write your code in `Main.java`, and check it:

```bash
ccm get two-cats
cd two-cats
ccm test
```
