Follow along with the lesson in `ListsDemo.java`. `Robot.java` is already done. Each section of the lesson has a matching `// --- Section ---` comment.

1. Make an `ArrayList<String>` of robot parts and print its size.
2. Add parts, get one by index, and insert one in the middle.
3. Change one with `set`, then remove one by value and one by index.
4. Search it with `contains` and `indexOf`.
5. Loop over it with a regular `for` loop, then with a for-each loop.
6. Make an `ArrayList<Robot>` and print each robot.
7. Make an `ArrayList<Integer>` of scores and add them up.

## In Labs

```bash
ccm get arraylist-demo
cd arraylist-demo
```

Run `ListsDemo` with the Run button, or:

```bash
javac *.java
java ListsDemo
```
