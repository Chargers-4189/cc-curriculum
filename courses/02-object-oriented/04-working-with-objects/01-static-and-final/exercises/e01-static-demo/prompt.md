Follow along with the lesson in `StaticTester.java`, `Robot.java` and `Units.java`. Each section of the lesson has matching `// --- Section ---` comments.

1. Call a few `Math` methods, then try `new Math()`.
2. Write static methods in `Units` and call them with the class name.
3. Try using an instance variable in a static method, and read the error.
4. Count robots with a static variable.
5. Add a `MAX_BATTERY` constant, then try to change it.
6. Make the robot's `name` final.

## In Labs

```bash
ccm get static-demo
cd static-demo
```

Run `StaticTester` with the Run button, or:

```bash
javac *.java
java StaticTester
```
