Read how many scores there are, then the scores. Print the average, then how many scores are **above** the average.

```
How many scores? 4
Enter the scores: 70 80 90 100
Average: 85.0
Above average: 2
```

Loop through the array **twice**: once for the average, once to count.

**Hint:** `(double) sum / count` avoids integer division.

## In Labs

Download it, write your code in `Main.java`, and check it:

```bash
ccm get above-average
cd above-average
ccm test
```
