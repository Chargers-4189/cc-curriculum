difficulty: easy

Read how many numbers there are, then read that many numbers into an array. Print them in **reverse** order on one line.

```
How many numbers? 5
Enter the numbers: 1 2 3 4 5
5 4 3 2 1
```

**Hints:**
- Create the array once you know the size: `int[] numbers = new int[count];`
- To go backwards, start at the **last index** (`length - 1`) and count down to 0.
