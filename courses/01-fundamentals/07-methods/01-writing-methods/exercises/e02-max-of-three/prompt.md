Write a method that returns the largest of three whole numbers:

```java
public static int max(int a, int b, int c)
```

`main` is already written for you. It reads three numbers and prints `max(...)`.

```
Enter three numbers: 4 9 2
Max: 9
```

**Challenge:** write a two-number `max` first, then make the three-number one call it.
