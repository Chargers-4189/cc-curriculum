Follow along with the lesson in `Switch.java`. Each section of the lesson has a matching `// --- Section ---` comment in the file.

1. Write the filing status `if` ladder.
2. Rewrite it as a `switch` with `break`s and a `default`. Try a few values for `status`, including one that isn't 0 to 3.
3. Remove the `break`s and see fall-through happen.
4. Use fall-through on purpose so two cases share the same code.
5. Try the arrow form.
