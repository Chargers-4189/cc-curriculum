Read a number, an operator, and another number, then print the answer. Use a `switch` on the operator (a `String`).

```
Enter a number: 7
Enter an operator (+ - * / %): *
Enter another number: 3
7 * 3 = 21
```

Use integer math for all five operators. Anything else prints `Unknown operator`.

**Hint:** `switch` works on Strings: `case "+":`

## In Labs

Download it, write your code in `Main.java`, and check it:

```bash
ccm get calculator
cd calculator
ccm test
```
