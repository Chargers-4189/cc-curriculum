---
title: "Month Name"
type: practice
difficulty: easy
---

Read a month number from 1 to 12 and use a `switch` to print the month's name. Anything else prints `Invalid month`.

```
Enter a month (1-12): 3
March
```

## In Labs

Download it, write your code in `Main.java`, and check it:

```bash
ccm get month-name
cd month-name
ccm test
```
