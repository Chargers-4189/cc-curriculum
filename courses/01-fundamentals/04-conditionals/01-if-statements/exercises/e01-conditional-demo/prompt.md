Follow along with the lesson in `Conditional.java`. Each section of the lesson has a matching `// --- Section ---` comment in the file.

1. Write an `if` that warns when the radius is 0 or below.
2. Add an `else` that prints the circle's area.
3. Write the drive / rent a car ladder with `age = 22`. Why does it never say "rent a car"? Fix the order.
4. Write the nested ID check, then flatten it with `&&`.
5. Use `&&` to safely check `dividend / divisor == 2` when `divisor` is 0.
6. Type the missing-braces and stray-semicolon traps. Predict what prints, then run them.
