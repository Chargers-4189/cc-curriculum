---
title: "Safe Division"
type: practice
difficulty: medium
---

Read two whole numbers and print the first divided by the second (integer division). If the second number is `0`, print a message instead of crashing.

```
Enter the dividend: 10
Enter the divisor: 3
10 / 3 = 3
```

```
Enter the dividend: 10
Enter the divisor: 0
Cannot divide by zero
```

## In Labs

Download it, write your code in `Main.java`, and check it:

```bash
ccm get safe-division
cd safe-division
ccm test
```
