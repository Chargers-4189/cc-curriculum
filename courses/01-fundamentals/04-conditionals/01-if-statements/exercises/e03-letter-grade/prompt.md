Read a score from 0 to 100 and print its letter grade:

| Score | Grade |
|---|---|
| 90 and up | A |
| 80 to 89 | B |
| 70 to 79 | C |
| 60 to 69 | D |
| below 60 | F |

```
Enter your score: 85
Grade: B
```

**Hint:** remember that the **first true branch wins**. What order should your conditions go in?

