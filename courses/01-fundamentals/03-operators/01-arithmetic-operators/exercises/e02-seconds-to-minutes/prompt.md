---
title: "Seconds to Minutes"
type: practice
difficulty: easy
---

Read a number of seconds and print how many **minutes** and leftover **seconds** that is.

```
Enter seconds: 500
500 seconds is 8 minutes and 20 seconds
```

**Hints:**
- There are 60 seconds in a minute. Integer division `/` gives the minutes.
- What operator gives you what's **left over**?

## In Labs

Download it, write your code in `Main.java`, and check it:

```bash
ccm get seconds-to-minutes
cd seconds-to-minutes
ccm test
```
