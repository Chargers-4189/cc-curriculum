---
title: "Is It Even?"
type: practice
difficulty: easy
---

Read a whole number and print `true` if it's even, `false` if it isn't. Use a relational operator, no `if` statements.

```
Enter a number: 10
Is even: true
```

**Hint:** a number is even when the remainder after dividing by 2 is 0.

## In Labs

Download it, write your code in `Main.java`, and check it:

```bash
ccm get is-it-even
cd is-it-even
ccm test
```
