---
title: "Same Word"
type: practice
difficulty: easy
---

Read two words and print whether they are the **same word**.

```
Enter the first word: robot
Enter the second word: robot
Same word: true
```

**Hint:** Strings use `.equals()`.

## In Labs

Download it, write your code in `Main.java`, and check it:

```bash
ccm get same-word
cd same-word
ccm test
```
