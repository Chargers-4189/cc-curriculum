## What is Programming

- Programming = giving a computer instructions
- Computers are literal: ask the room to give you instructions to "make a sandwich" or "walk to the door" and follow them exactly
- Languages exist to make communicating with computers easier; name a few (Java, Python, C++, HTML)

## Why Program

- On the robot: automation, controlling motors, communication between components
- Human vs computer table: we're creative but inconsistent; computers are consistent but have no creativity
- Programming combines the two: we design, the computer executes

## Hardware vs Software

- Hardware = physical (CPU, RAM); software = stored instructions (OS, our code)
- Kinds of computers: desktops, laptops/phones/tablets, servers
- Mention their workspace runs on a server, not their Chromebook

## The Computer Model

- Input → storage → processing → output
- Ask for examples of each; then map the robot onto it (sensors/controllers → roboRIO → motors)

## Memory

- RAM: fastest, temporary, cleared on power off
- HDD/SSD: permanent, slower
- Analogy: RAM is your desk, storage is the filing cabinet
- Why unsaved work disappears when a computer crashes

## Files and Folders

- File = data with a format at the end (`.png`, `.java`)
- Folders organize files and can nest
- Repositories = folders for code that track changes; preview of GitHub

## IDE

- Editor + repository + runtime + deployment in one tool
- We use VS Code in the workspace and on the robot
