## Curriculum Overview

This course is designed for a 15-week course, with 2 lessons per week. These lessons or sessions are labeled A and B. Session A is conducted in person on Mondays, while session B is held online at 5:00 PM on Fridays. Both sessions are recorded.

We try to include as much as possible in knowledge, material, and experience to prepare you for the FRC season. This is a **zero-to-robot** outline:

- **Core material** you will learn over these 15 weeks covers the necessary components: Java, GitHub, WPILib, and Electrical.
- **Workshops** are separate sessions where you can choose to attend and delve deeper into specific topics such as vision, swerve, mechanisms, autonomous driving, and third-party software.

## Prerequisites of This Course

This course does **NOT** require any previous experience with programming. We strive to make this course as accessible as possible, enabling anyone to learn programming and independently work on the robot.

- Of course, any prior educational experience will make it easier to understand the course

Personal computers are recommended! We designed the course so that you're able to learn from your Chromebooks. However, a personal computer will allow you to use software and test code for the robot which will be needed in the FRC season.

Lastly, we encourage you to be curious, eager to learn, and to educate yourself outside of club hours so that you are prepared and informed throughout the course.

## What to Expect

Before we write any code, the first lessons make sure you're comfortable with:

- **Using a computer:** file management, installing software, and navigating the operating system
- **Computers:** what inputs and outputs are, what folders and files are
- **Navigating software:** understanding how to navigate user interfaces and use them
