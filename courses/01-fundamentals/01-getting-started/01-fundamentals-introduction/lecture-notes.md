# Introduction - Lecture Notes

## Introductions

- Introduce yourself and the assistants
- Have students introduce themselves: name, grade, any programming experience, what part of the robot interests them
- Point out the contact info on the last slide; email is the best way to reach us outside club

## Curriculum Overview

- 15 weeks, 2 sessions a week
  - A: Monday, in person
  - B: Friday 5:00 PM, online
  - Both are recorded; missed sessions can be caught up on Charging Courses
- "Zero-to-robot": by the end they should be able to work on the robot code independently
- Core material vs workshops
  - Core: Java, GitHub, WPILib, Electrical (everyone)
  - Workshops: optional deep dives (vision, swerve, mechanisms, autonomous, third-party software)

## Prerequisites

- No programming experience needed; stress this so nobody feels behind
- Chromebooks work for the whole course thanks to the workspaces
- Personal computers recommended for the season (robot software and testing need them)
- Biggest prerequisite is curiosity: practice outside club hours

## What to Expect Today

- Signups first (Charging Courses, GitHub)
- Then basics of computers: files, folders, hardware vs software
- Ask questions early and often
