# Java Workspace - Lecture Notes

Best done live: share your screen and have everyone follow along in their own workspace.

## Starting the Workspace

- Labs → workspace → Start; wait for Running
- Workspaces stop when idle; files are kept, just start it again
- Common issue: workspace won't start → API key missing or deleted (back to Workspace Access)

## VS Code Tour

- Open code-server; point at each area: Activity Bar, Explorer, Editor, Panel, Status Bar
- ☰ menu holds File/Edit/View/Terminal in the browser
- This is the same editor used for the robot, so time spent here pays off later

## Folders and Files

- Open Folder → `/home/coder`; accept the trust prompt
- Have everyone create a `fundamentals` folder, then a file `Test.java` inside it
- Rename it, then delete it, so they've done each once
- Connect back to Basics of Computers: folders organize files, files end in a format

## Saving

- Show the dot on an unsaved tab
- Run old code on purpose to show "it runs what's saved"
- Suggest turning on Auto Save

## Terminal

- Open with ☰ > Terminal > New Terminal (Ctrl + ` may not work on every keyboard)
- Walk through `pwd`, `ls`, `cd`, `cd ..`, `mkdir`, Tab completion
- Preview `javac` / `java`; don't explain them yet, that's How Java Works

## Chromebook Gotchas

- Ctrl + W closes the browser tab, not the file
- Command Palette (Ctrl + Shift + P) works when a shortcut doesn't
