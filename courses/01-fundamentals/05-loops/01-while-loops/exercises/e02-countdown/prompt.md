---
title: "Countdown"
type: practice
difficulty: easy
---

Read a whole number and count down from it to 1, one number per line, then print `Liftoff!`.

```
Enter a number: 3
3
2
1
Liftoff!
```

If the number is 0 or less, just print `Liftoff!`.

## In Labs

Download it, write your code in `Main.java`, and check it:

```bash
ccm get countdown
cd countdown
ccm test
```
