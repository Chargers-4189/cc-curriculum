---
title: "Count the Digits"
type: practice
difficulty: medium
---

Read a positive whole number and count how many digits it has.

```
Enter a positive number: 4520
4520 has 4 digits
```

**Hints:**
- `n / 10` removes the last digit. Keep doing it while there are digits left.
- You'll change `n` in the loop, so save the original number first if you want to print it at the end.
