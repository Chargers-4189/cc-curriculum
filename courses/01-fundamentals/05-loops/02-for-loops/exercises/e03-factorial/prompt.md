Read a whole number `n` from 0 to 20 and print `n!` (n factorial), which is `1 * 2 * 3 * ... * n`. By definition, `0!` is `1`.

```
Enter n (0-20): 5
5! = 120
```

**Hint:** factorials get **huge**. `13!` is already too big for an `int` (remember overflow?), so use a `long` for the answer.
