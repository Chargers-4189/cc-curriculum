Follow along with the lesson in `ForLoops.java`. Each section of the lesson has a matching `// --- Section ---` comment in the file.

1. Print "Welcome to Java!" 10 times with a `for` loop.
2. Print the loop variable each pass to see the order of execution. Try to use it after the loop.
3. Count down from 5 to 1, then count by 5s from 0 to 20.
4. Print a 9 x 9 multiplication table with nested loops.
5. Use `break` to stop once a sum reaches 100, and `continue` to add only the odd numbers.
