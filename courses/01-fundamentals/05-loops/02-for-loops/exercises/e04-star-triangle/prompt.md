title: "Star Triangle"
type: practice
difficulty: medium
---

Read a number of rows and print a right triangle of stars with **nested** for loops.

```
Enter the number of rows: 4
*
**
***
****
```

**Hints:**
- The outer loop picks the row (1 to `rows`).
- The inner loop prints that many stars. How many stars does row 3 have?
- Don't forget the `println()` that ends each row.

## In Labs

Download it, write your code in `Main.java`, and check it:

```bash
ccm get star-triangle
cd star-triangle
ccm test
```
