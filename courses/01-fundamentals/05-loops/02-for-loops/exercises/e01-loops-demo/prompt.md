# Loops (Follow Along)

## Getting the Files

Open a terminal in your workspace and run:

```bash
ccm get loops-demo
cd loops-demo
```

## Task

Follow along with the lecture in `Loops.java`.

1. Use a `while` loop to add up the numbers 1 through 9.
2. Write a **sentinel** loop: keep reading integers and adding them until the user enters `0`, then print the sum.
3. Print "Welcome to Java!" 10 times with a `for` loop.
4. Count down from 5 to 1 on one line.
5. Print a 9 x 9 multiplication table with **nested** for loops.
6. Use `break` to stop adding once the sum reaches 100.
7. Use `continue` to add up only the odd numbers from 1 to 20.
