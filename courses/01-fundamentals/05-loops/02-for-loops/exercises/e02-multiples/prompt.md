Read a whole number and print its first **5** multiples on one line, separated by spaces.

```
Enter a number: 3
3 6 9 12 15
```

**Hint:** loop `k` from 1 to 5 and print `number * k`. Use `print`, not `println`, inside the loop.

## In Labs

Download it, write your code in `Main.java`, and check it:

```bash
ccm get multiples
cd multiples
ccm test
```
