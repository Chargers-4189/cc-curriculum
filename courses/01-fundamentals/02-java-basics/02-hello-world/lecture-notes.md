## Live Coding

- Everyone creates `Hello.java` in their workspace and types along; don't paste
- Build it in order: class → main → println, running at each step to show what errors look like
- Run with the Run button, then again with `javac` / `java` in the terminal

## Points to Hit

- File name = public class name (rename the file to show the compile error)
- `println` vs `print`: add two `print` calls to show they land on one line
- Strings go in double quotes
- Semicolons end statements; braces must match
- Java is case-sensitive: `system` vs `System`

## Reading Errors

- Delete a semicolon on purpose; read the error together: file, line number, "';' expected"
- Habit to build: read the first error first, fix it, run again

## Discussion Questions (slide 2)

- Readability: others (and future you) read your code
- Other outputs: files, screens, motors on the robot
- Why main: the JVM needs a starting point
- Semicolon
