# Hello World (Follow Along)

## Getting the Files

Open a terminal in your workspace and run:

```bash
ccm get hello-demo
cd hello-demo
```

## Task

Follow along with the lecture to write your first Java program.

1. In your workspace, create a file named `Hello.java`.
2. Declare a class named `Hello`.
3. Inside it, write the `main` method.
4. Inside `main`, print `Hello World` to the console.
5. Run it! Try both the **Run** button and the terminal (`javac Hello.java`, then `java Hello`).

When you're done, try changing the message or adding a second `System.out.println` line.
