Follow along with the lesson to write your first Java program in `HelloWorld.java`.

1. Declare a class named `HelloWorld` (it has to match the file name).
2. Inside it, write the `main` method.
3. Inside `main`, print `Hello World` to the console.
4. Run it! Try both the **Run** button and the terminal (`javac HelloWorld.java`, then `java HelloWorld`).
5. Add a few `print` and `println` lines and see where each one ends up.
6. Break it on purpose: delete a semicolon, change `System` to `system`, remove the quotes. Read each error, then fix it.
