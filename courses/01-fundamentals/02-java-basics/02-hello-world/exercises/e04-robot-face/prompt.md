Print this robot face, exactly as shown (spaces included):

```
 _____
| o o |
|  ^  |
|_____|
```

**Hints:**
- Spaces inside the quotes count. `" _____"` starts with a space.
- Try `print` instead of `println` on the first line to see what changes.
