---
title: "Swap Two Values"
type: practice
difficulty: medium
---

Read two whole numbers into `a` and `b`, **swap** them, then print them.

```
Enter a: 5
Enter b: 3
a = 3, b = 5
```

**Hint:** if you write `a = b;` first, the old value of `a` is gone forever. Save it in a third variable first:

```java
int temp = a;
```
