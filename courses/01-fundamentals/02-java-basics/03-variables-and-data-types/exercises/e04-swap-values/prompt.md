---
title: "Swap Two Values"
type: practice
difficulty: medium
---

Read two whole numbers into `a` and `b`, **swap** them, then print them.

```
Enter a: 5
Enter b: 3
a = 3, b = 5
```

**Hint:** if you write `a = b;` first, the old value of `a` is lost. Save it in a third variable:

```java
int temp = a;
```

## In Labs

Download it, write your code in `Main.java`, and check it:

```bash
ccm get swap-values
cd swap-values
ccm test
```
