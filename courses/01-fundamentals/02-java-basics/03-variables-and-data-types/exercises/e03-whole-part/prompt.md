title: "Whole Part"
type: practice
difficulty: easy
---

Read a decimal number, then print just the whole part by **casting** it to an `int`.

```
Enter a decimal: 7.89
Whole part: 7
```

Notice that `7.89` becomes `7`, not `8`. Casting cuts off the decimal instead of rounding.
