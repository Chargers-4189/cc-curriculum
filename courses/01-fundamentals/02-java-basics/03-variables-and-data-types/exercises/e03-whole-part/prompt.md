---
title: "Whole Part"
type: practice
difficulty: easy
---

Read a decimal number, then print just the whole part by **casting** it to an `int`.

```
Enter a decimal: 7.89
Whole part: 7
```

Casting cuts off the decimal, so `7.89` becomes `7`.

## In Labs

Download it, write your code in `Main.java`, and check it:

```bash
ccm get whole-part
cd whole-part
ccm test
```
