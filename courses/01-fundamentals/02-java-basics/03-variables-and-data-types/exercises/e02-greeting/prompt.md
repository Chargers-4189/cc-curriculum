Ask for the user's name and age, then greet them.

```
Enter your name: Ada
Enter your age: 15
Hi Ada, you are 15
```

The prompts are already in your starter code. Store the name in a `String` and the age in an `int`, then print the greeting **exactly** like the example.

**Hint:** `input.nextLine()` reads text, `input.nextInt()` reads a whole number.
